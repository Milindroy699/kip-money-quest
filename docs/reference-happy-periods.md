# Reference teardown: "Happy Periods" app (basic reference only)

Reviewed from a 2 m 40 s screen recording. Treat it as a floor to beat, not a template.

## What it does
- **Home is a menu of 4 mini-games:** Quiz, Catch Game, Runner, Sort. There is an XP chip, an optional Google sign-in ("Continue offline"), and an AI chat bar ("Let's talk about periods…") with a character avatar.
- **Myth Buster Quiz:** 3 questions, a progress bar, all answer buttons in the same pink, a tiny "Correct!" text, and a "Congratulations +20 XP" modal.
- **Catch the Good Foods:** a basket catches falling good foods. Catching a bad food opens a **blocking modal** ("Avoid Candy!", with the reason) and costs a life.
- **Period Runner:** a 2D side-scroller where you tap to jump. Bad items show a fact toast. Three lives, then "Game Over".
- **Sort the Truth:** endless True/False statements with a score and accuracy counter.

## Worth borrowing
| Idea | How Kip uses it |
|---|---|
| Games are instantly understandable, with a "How to play" card before each | Each runner mode starts with a 3-line brief from Kip |
| A teachable moment *at* the mistake | Kip's in-run tips appear at the moment of the event, but **don't pause play** |
| Play works offline; sign-in is optional | Phase 1 is fully on-device. Signup comes later (onboarding step 7) |
| AI chat companion on the home screen | **"Ask Kip"** in Phase 2: a guard-railed AI chat (education only, no advice, parental controls) |

## Where it falls short, and what we do instead
| Gap in the reference | Kip: Money Quest |
|---|---|
| Games are separate islands with no story, path or goal | **Worlds, a path map and Future You.** Every game feeds one journey toward the player's own dream |
| Mechanics don't model the concept (catch good / avoid bad) | **The mechanic *is* the concept.** The Melt really shrinks idle coins, the snowball multiplier really compounds, and a cash-out ramp really resets it. Players *feel* inflation and compounding |
| Learning arrives as blocking modals after failure | **Non-blocking Kip tips** during play, plus a **post-run debrief** that explains *your* run ("You carried 23 coins past a gate and The Melt ate 9") |
| Trivia and True/False repetition (some statements repeat) | **Scenario questions** with a **targeted explanation for every wrong option**, plus **predict-then-reveal** widgets: guess first, then drag the slider to see the truth |
| Lives and "Game Over" punish learners | No lives. A run ends early if The Melt catches you, but **you keep what you banked**, which is itself the lesson |
| Little juice: tiny "Correct!" text, flat buttons | Haptics, coin pops, an animated multiplier reveal, Kip's expressions, chunky pressable buttons, clear correct/incorrect states |
| XP only; no habit loop | Knowledge SIP streak with a compounding multiplier, emergency-fund freezes, Dividend Day, FinIQ, shell rings, nudges, leagues |
| Single-mode home | A **Learn path first** (what to do next is obvious), with Kip Run and Cards one tap away |
